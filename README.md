# AI-Powered Intelligent Campus Helpdesk

## About the Project

The AI-Powered Intelligent Campus Helpdesk is a final-year engineering project designed to help students access college-related information and manage service requests through a single platform.

The system aims to provide AI-powered answers to campus-related queries, display relevant source information, and allow students to raise and track service tickets.

## Key Features

- AI-powered campus chatbot
- College information and knowledge base
- Student service ticket creation and tracking
- Admin dashboard for ticket management

## Technology Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Python, FastAPI
- **AI and Retrieval:** Sentence Transformers, ChromaDB or FAISS
- **Database:** SQLite (initial prototype)
- **Version Control:** Git and GitHub

## Project Status

Currently in the initial development phase. Features will be implemented and tested incrementally.

## Team

Developed by a team of four final-year engineering students.

## Future Scope
